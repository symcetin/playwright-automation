JavaScript vs TypeScript:
	
	JavaScript: 
		1. Dynamically Typed, allows variables to change types at runtime.

		2. Interpreted language that runs without prior compilation.

		3. Errors are typically caught at runtime.

		4. Less maintainable in large projects (no Type Safety).

		5. Does not support all OOP prinnciples

		6. Access modifiers: no explicit access modifiers, properties are public by default


	TypeScript:
		1. Statically Typed, enabls type checking at compile time, which helps catch errors early.

		2. Compiled language that needs to be compiled into JavaScript before execution.

		3. Errors are caught at compile time (reduces runtime errors and improves code reliability).

		4. Improves maintainability and readability, especially in large codebases (Type Safety).

		5. Supports all OOP prinnciples.

		6. Access modifiers: public, protected, private

	Disadvantages of selenium:
		1. Flaky tests
		2. wait issues (explicit waits)
		3. scrolling
		4. after each sprint regression suit is getting larger and execution time is taking longer
		5. Test passing rate (80%)
		6. depended on Grid/TestNG/PyTest for parallel execution, and JUnit/TestNG for test runner

	Advantages of playwright:
		1. no flaky tests
		2. Auto waiting
		3. Auto scrolling
		4. auto switching
		5. has parallel execution and has test runner6. Global configuration (head/headless, cross browser, video recording, screenshots.)
